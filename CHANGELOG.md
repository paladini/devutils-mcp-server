# Changelog

All notable changes to this project will be documented in this file.

## [1.1.0] - 2026-07-08

### Added

- Official MCP Registry entry (`io.github.paladini/devutils-mcp-server`).
- `mcpName` field and `server.json` for registry publishing.
- Plugin install paths in README (Cursor + Claude Code).
- SECURITY.md and GitHub issue templates.

### Changed

- npm package description aligned with actual tool set.
- Smithery config uses `npx -y` for non-interactive install.

### Removed

- REGISTRY_PUBLISH.md (registry is live; see DISTRIBUTION in plugin repo for submission tracking).

## [1.0.0] - Initial release

- 36 local developer utility MCP tools.
- npm, Docker, and stdio transport support.
